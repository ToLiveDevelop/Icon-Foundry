01 / ВЫБОР

Не ограничивайтесь одним паком

Объедините до 10 паков с приоритетом перетаскиванием и замените отдельные иконки на изображения из других паков или своих файлов — с предпросмотром.

02 / ФОРМА

Единый характер

Выбирайте готовую форму, настройте углы или загрузите маску из PNG с нужным масштабом. Разрешение экспорта выбирается отдельно для каждого пака: исходное, 256, 192, 128 или 96 px. Фон, накладка и маска используют максимальный выбранный размер. После экспорта тема свыше 290 МиБ получает предупреждение о возможной невидимости в «Темах» HONOR. В настройках фона отдельно регулируются масштабы фона и иконок; результат виден на трёх системных и трёх иконках из пака. Для системных иконок без замены доступны фильтры цветокоррекции и позиции — можно изменить цвет, масштаб, смещение и наклон.

03 / ШАБЛОНЫ

Настройте однажды

Сохраните назначения и параметры в шаблоне. В настройках можно сохранить файл бэкапа всех шаблонов с обложками, обоями, пользовательскими иконками и масками. Восстановление добавляет отсутствующие шаблоны, не заменяя существующие. После обновления иконпака пересоберите тему со свежими изображениями.

ОТ ПАКА ДО ТЕМЫ

Четыре простых шага.

Только локальная обработка на вашем телефоне.

  1. Установите иконпак

    Подойдёт совместимый Android-пак с appfilter.xml.

  2. Соберите свой набор

    Выберите один или несколько паков-основ, название, обложку, форму и при желании свои обои.

  3. Создайте тему

    Предоставьте доступ к Honor/Themes. Имя .hnt создаётся автоматически; если тема Icon Foundry с таким названием уже есть, добавится v2, v3 и т. д. Можно включить иконки для будущих приложений.

  4. Примените в «Темах»

    Откройте штатное приложение HONOR и выберите созданную тему. Icon Foundry ничего не применяет автоматически.

Полезно знать

С версии 1.38 приложение допускает установку на Android 14 (API 34), включая HONOR MagicOS 8. Проверки API и сборки пройдены, но работа на реальном Android 14 / MagicOS 8 пока не проверена. Поддержка созданной темы, размытия папок и скрытия VoLTE зависит от версии «Тем» и лаунчера.

Для исправления серого фона иконок в стеке папки нужно применить тему целиком. В этом режиме «Темы» HONOR могут заменить текущие обои запасными, если вы не добавили свои. Выбранное изображение включается для рабочего стола и экрана блокировки.

Для стеклянного фона маленьких папок тема включает настройки совместимости HONOR без замены изображения папки. Результат может различаться в разных версиях лаунчера.

В список включаются приложения, установленные только в доступном рабочем профиле, например Island. Приватное пространство Android обычным приложениям недоступно. Фильтры применяются только к установленным приложениям без иконки из пака или ручной замены.

Каждый экспорт создаёт новый файл, не заменяя старые. Название самой темы не меняется: это не гарантирует обновления записи в «Темах». Если видна старая версия, сначала удалите её запись в HONOR, затем создайте тему снова.

Совместимость зависит от версии лаунчера и иконпака. Для установки APK Android запросит разрешение на установку из выбранного источника. Начиная с версии 1.36 сборки подписаны собственным ключом автора.

В версии 1.36 добавлен предпросмотр темы из черновика, уменьшен размер PNG без потери качества и ускорен выбор иконпаков. Версия 1.35 — последняя с прежней подписью. Перед переходом с неё или более старой версии сохраните бэкап шаблонов через настройки в файл вне данных приложения: Android потребует удалить старую версию перед установкой новой. После установки восстановите бэкап; несохранённый черновик в него не входит. Тестовые 1.36-test и 1.36-test2 обновляются без удаления данных.

В настройках приложения доступны русский и английский языки, светлое, тёмное и системное оформление. По умолчанию оформление следует системе, язык выбирается при первом запуске.

Некоммерческое использование разрешено с сохранением авторства. Для коммерческого использования нужно предварительное письменное разрешение автора. Условия лицензии.
